# Портфоліо — Демид, веброзробник

Односторінковий сайт-портфоліо (лендинг). Чистий **HTML + CSS + JavaScript**,
без збірки та залежностей. Шрифти вбудовано в файл — сайт працює офлайн і не
робить зовнішніх запитів.

> Ця гілка (`claude/demyd-dev-portfolio`) містить **лише портфоліо** — жодного
> Next.js та `package.json`, тож Netlify нічого не збирає, а просто показує сайт.

## Як опублікувати
- **Netlify (найпростіше):** Add new site → **Deploy manually** → перетягни
  всю цю папку (в ній `index.html` у корені, без `package.json`).
- **GitHub Pages:** Settings → Pages → Deploy from branch → `claude/demyd-dev-portfolio` / root.
- **Локально:** відкрий `index.html` у браузері.
