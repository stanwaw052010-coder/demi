# Сайт-візитка · Daria — SMM спеціаліст & таргетолог

Односторінковий сайт для особистого бренду [@darisha_smm_target](https://www.instagram.com/darisha_smm_target/).
Без збірки, без залежностей — звичайні HTML, CSS і JS. Відкривається подвійним кліком по `index.html`.

```
.
├── index.html          ← увесь текст сайту
├── styles.css          ← кольори, шрифти, верстка
├── script.js           ← меню, анімації, форма
├── assets/
│   ├── fonts/          ← шрифти (вшиті у сайт, не тягнуться з інтернету)
│   └── img/logo.jpg    ← аватар/лого
├── tools/build-artifact.py  ← збирає все в один файл
└── dist/artifact.html  ← той самий сайт одним файлом (для швидкого показу)
```

## Кольорова гама

Взята з візуалів профілю. Усі кольори — у `styles.css`, у блоці `:root`.
Щоб змінити відтінок на всьому сайті, достатньо поправити одне значення.

| Змінна | Значення | Де використовується |
|---|---|---|
| `--rose` | `#E8619A` | основний рожевий, градієнт «SMM», кнопки |
| `--rose-deep` | `#B92C63` | акцентний текст, лейбли, посилання |
| `--rose-soft` | `#F7A9C9` | м'які акценти, кільце навколо фото |
| `--rose-pale` | `#FCDCEA` | заливка іконок і кружечків |
| `--ink` | `#1B0F14` | основний текст (чорний з рожевим підтоном) |
| `--ground` | `#FFF6FA` | фон сторінки |
| `--silk-1/2/3` | рожеві + персиковий | «шовкові» плями на фоні |

Темна тема налаштована окремо — сайт автоматично підлаштовується під тему
телефона чи браузера відвідувача.

## Шрифти

- **Poiret One** — великі заголовки
- **Arsenal SC** — український шрифт, капітель: навігація, кнопки, підзаголовки
- **Lora** — основний текст

Усі три лежать у `assets/fonts/` і підключені локально, тож сайт працює навіть
без інтернету і не залежить від Google Fonts. Ліцензії (OFL) — там само.

## Що треба замінити перед публікацією

1. **Фото в портфоліо.** У секції «Роботи» зараз стилізовані заглушки з іконками.
   Покладіть свої зображення в `assets/img/` і замініть у `index.html` блок
   ```html
   <span class="tile__art tile__art--a" aria-hidden="true"> … </span>
   ```
   на
   ```html
   <img class="tile__img" src="assets/img/kejs-kavyarnya.jpg" alt="Кейс для кав'ярні" loading="lazy" />
   ```
   Решта стилів підхопиться сама. Найкраще підходять вертикальні фото 1080×1350.
2. **Своє фото у першому екрані** — `assets/img/logo.jpg` (зараз там аватар з
   Instagram, він невеликий; краще покласти якісніше фото тим самим ім'ям).
3. **Контакти.** Зараз є тільки Instagram. Якщо треба Telegram/пошту — додайте
   ще один блок `<a class="social" href="…">` у секції «Контакти».
4. **Відгуки.** Блоку з відгуками навмисно немає — його варто додати тільки з
   реальними скріншотами від клієнтів.
5. **Тексти в FAQ** — це робочі формулювання, перечитайте і підправте під себе
   (терміни, умови роботи).

Цін і готових пакетів на сайті немає: вартість формується індивідуально,
про що прямо сказано в секції «Індивідуальний підхід» і в FAQ.

## Форма зворотного зв'язку

Кнопка «Надіслати запит» збирає текст заявки, копіює його в буфер обміну і
відкриває ваш Direct — людині лишається вставити повідомлення. Це працює без
сервера й нічого не коштує.

Якщо захочете отримувати заявки на пошту — найпростіше підключити безкоштовний
[Formspree](https://formspree.io): додати `action` і `method` до тегу `<form>`
у `index.html` і прибрати обробник `form.addEventListener("submit", …)` зі `script.js`.

## Як опублікувати

Сайт лежить у корені гілки `claude/smm-website-color-scheme-ivgf8a`, окремо від
інших проєктів у цьому репозиторії. Жодної збірки не потрібно — це просто файли.

**Netlify (найшвидше, безкоштовно, свій домен):**
відкрийте [app.netlify.com/drop](https://app.netlify.com/drop) і перетягніть туди
папку з цими файлами. Сайт з'явиться за кілька секунд.

**GitHub Pages:** у налаштуваннях репозиторію → Pages оберіть гілку
`claude/smm-website-color-scheme-ivgf8a` і папку `/ (root)`.

**Vercel:** імпортуйте репозиторій, гілка — `claude/smm-website-color-scheme-ivgf8a`,
Root Directory залиште порожнім, фреймворк — «Other», Build Command — порожній.

## Один файл замість папки

```bash
python3 tools/build-artifact.py
```

Збере `dist/artifact.html` — увесь сайт (стилі, скрипти, шрифти, картинки)
в одному файлі. Зручно надіслати клієнту в месенджері або відкрити з флешки.
