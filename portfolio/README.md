# Портфоліо — Демид, веброзробник

Сучасний односторінковий сайт-портфоліо (лендинг) для веброзробника, що
спеціалізується на сайтах для б’юті-сфери. Темна преміальна тема, золоті
акценти, анімації при скролі та ефект друкування в hero-секції.

## Технології
Чистий **HTML + CSS + JavaScript**, без збірки та залежностей. Шрифти
(Montserrat + Inter, підмножина з підтримкою кирилиці) вбудовано прямо у файл
через base64 — сайт працює навіть офлайн і не робить зовнішніх запитів.

## Як відкрити / опублікувати
- **Локально:** просто відкрий `index.html` у браузері.
- **Хостинг:** завантаж `index.html` на будь-який статичний хостинг —
  GitHub Pages, Netlify, Vercel, Cloudflare Pages тощо. Це один файл.

## Що варто відредагувати під себе
Усе — у файлі `index.html`:

1. **Особисті фото (теніс).** У hero є дві плашки-плейсхолдери
   (`.photo-front` і `.photo-back`). Щоб додати своє фото, заміни фон блоку на
   зображення, напр.:
   ```css
   .photo-front{ background:url('front.jpg') center/cover; }
   .photo-back { background:url('back.jpg')  center/cover; }
   ```
   (шукай коментар «Дві плашки-плейсхолдери…» у розмітці).

2. **Прайс-лист.** Блок `<section id="pricing">`. Готовий прайс не було
   надано, тож там **орієнтовні** тарифи (Лендінг / Бізнес-сайт / Під ключ).
   Заміни назви, ціни та пункти на свої актуальні (шукай коментар «ПРАЙС»).

3. **Telegram.** За побажанням кнопка Telegram веде **на цей сайт**
   (`href="#home"`), а не напряму в t.me. Щоб зробити пряме посилання —
   заміни `href` на `https://t.me/mortual1aa` (шукай коментар «Telegram»).

4. **Бейдж.** У hero стоїть бейдж «Senior HTML/CSS Developer» — за бажанням
   зміни текст.
