# Telegram-бот студии Profi Time

Бот для студии лазерной эпиляции и лазерного омоложения **Profi Time**
(г. Вышгород). Витрина услуг, воронка заявок с ручным подтверждением
владелицей и инструмент удержания клиента в курсе процедур.

Весь интерфейс для клиенток — на украинском. Комментарии в коде и эта
документация — на русском.

**Стоимость разработки и эксплуатации — 0 грн.** Никаких платных API, БД,
хостингов и библиотек. Long polling: не нужны домен, SSL, ngrok и белый IP.

---

## ⚠️ Главное, что нужно понимать про этого бота

**Бот не ведёт свой календарь свободного времени.** Единственный источник
правды по занятости — **Bookon**. Бот не знает, какие слоты реально свободны,
поэтому нигде не показывает время как «свободное».

Отсюда два пути записи:

| Путь | Как работает |
|---|---|
| **⚡ Записатися онлайн** (основной) | Кнопка ведёт на Bookon. Там видно реальное свободное время, подтверждение приходит сразу. Кнопка есть в главном меню, в карточке каждой услуги, в результате калькулятора, в результате теста, в напоминании о курсе и в контактах. |
| **📝 Залишити заявку** (запасной) | Клиентка выбирает **желаемую** дату и **желаемый** промежуток (утро / день / вечер). Владелица получает заявку, вносит запись в Bookon и сообщает боту фактические дату и время. Только после этого клиентке уходит подтверждение. |

Второй путь нужен, чтобы не терять тех, кто не хочет разбираться со сторонним
сайтом, и чтобы у владелицы оставался контроль.

## 1. Запуск за 10 минут

### Шаг 1. Токен бота (2 минуты)

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`.
3. Введите **отображаемое имя**, например: `Profi Time | Лазерна епіляція`.
4. Введите **username** — латиницей, обязательно заканчивается на `bot`.
5. BotFather пришлёт строку вида `1234567890:AAH4x-...` — это **токен**.

Полезно сразу там же: `/setuserpic` (аватар студии), `/setdescription`
(текст, который видно до кнопки «Запустить»).

### Шаг 2. Telegram ID владелицы (1 минута)

1. Найдите **@userinfobot**, отправьте `/start`.
2. В ответе строка `Id: 123456789` — это числовой ID.
3. Нужен ID **аккаунта владелицы** — именно он получает заявки и панель.

> Можно указать несколько ID через запятую — например, владелица и менеджер.

### Шаг 3. Установка (5 минут)

Нужен **Python 3.11 или новее** (`python --version`).

```bash
cd profitime_bot

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

### Шаг 4. Настройка (1 минута)

```bash
cp .env.example .env             # Windows: copy .env.example .env
```

Откройте `.env` блокнотом и заполните две строки:

```env
BOT_TOKEN=1234567890:AAH4x-abcdefghijklmnopqrstuvwxyz012
ADMIN_IDS=123456789
```

Файл `.env` в git не попадает — секреты не утекут.

### Шаг 5. Запуск

**Windows — проще всего:** двойной клик по **`start_bot.bat`**.
Он сам создаст окружение при первом запуске, поставит зависимости
и поднимет бота заново, если тот упадёт из-за обрыва интернета.

**Или вручную:**

```bash
python bot.py
```

**Linux / macOS / Termux:** `./start_bot.sh` — делает то же самое.

В консоли появится:

```
INFO | database.db      | База даних готова: .../bot.db
INFO | utils.scheduler  | Планувальник запущено...
INFO | bot              | Бот @ваш_бот запущено. Студія: Profi Time
```

Откройте бота в Telegram и нажмите **Запустить**. Владелице дополнительно
доступна команда `/admin`.

Остановка — `Ctrl+C`.

Если в `.env` чего-то не хватает, бот не упадёт с трейсбеком, а напишет
понятным текстом, что именно исправить.

## 2. Что должна сделать владелица (важно!)

**Заявку нужно обрабатывать в два действия, а не в одно:**

1. Приходит уведомление «🔔 НОВА ЗАЯВКА».
2. **Сначала** владелица вносит запись в Bookon (или проверяет, что время свободно).
3. **Потом** нажимает в боте «✅ Підтвердити» и вводит **реальные** дату и время
   в формате `20.08 14:30`.

Почему именно так: бот не видит Bookon. Указанные владелицей дата и время —
это то, от чего он считает напоминания клиентке (за 24 часа и за 2 часа) и
интервал до следующего сеанса курса. Если ввести не то время, что в Bookon,
напоминания уйдут не вовремя.

Остальные кнопки под заявкой:

- **🕐 Запропонувати інший час** — владелица вводит вариант, клиентка получает
  кнопки «Підходить» / «Не підходить, зв'яжіться зі мною».
- **❌ Відхилити** — выбор причины из списка или своя формулировка. Клиентке
  уходит вежливое сообщение с альтернативой.
- **📞 Телефон** — показывает номер крупно, всплывающим окном.

Если заявка висит без ответа дольше 3 часов, бот напомнит о ней сам.

## 3. Как заменить прайс, добавить акцию, изменить тексты

Инструкция для не-программиста. Всё правится обычным блокнотом.

### Как поменять цену

1. Откройте файл **`config.py`**.
2. Найдите строку с нужной зоной. Она выглядит так:

```python
"w_armpits": {"code": "w_armpits", "name": "Пахви", "group": "women",
              "price": 450, "package_price": 1800, "duration": 15,
              "sessions": 6, "interval_days": 30},
```

3. Меняйте только числа после двоеточия:

| Что | Где | Пример |
|---|---|---|
| Цена за один сеанс | `"price"` | `450` → `500` |
| Цена пакета из 5 сеансов | `"package_price"` | `1800` → `2000` |
| Длительность в минутах | `"duration"` | `15` → `20` |
| Сколько сеансов в курсе | `"sessions"` | `6` → `8` |
| Через сколько дней следующий | `"interval_days"` | `30` → `28` |

4. Сохраните файл, нажмите `Ctrl+C` в чёрном окне и запустите `python bot.py` снова.

**Правила, чтобы ничего не сломать:**
- кавычки и запятые не трогайте — меняйте только то, что между кавычками или числа;
- цены без пробелов и без слова «грн»: `450`, а не `450 грн`;
- название зоны меняется в `"name"` — на украинском, в кавычках.

### Как добавить зону

Скопируйте любую строку целиком, вставьте рядом и поменяйте `code`
(должен быть уникальным, латиницей), `name` и числа. Код нужно поменять
**в двух местах** — в ключе слева и в `"code"` внутри.

### Как удалить зону

Удалите её строку целиком (от `"w_...":` до закрывающей `},`).

### Как добавить акцию

Два способа.

**Способ 1 — прямо из бота (проще):** `/admin` → **✏️ Акції** →
**➕ Додати акцію**. Бот спросит название, описание, старую и новую цену,
дату окончания и покажет предпросмотр перед публикацией. Просроченные акции
скрываются автоматически.

**Способ 2 — в `config.py`:** найдите блок `PROMOTIONS` и добавьте:

```python
{
    "code": "p_new",
    "title": "Назва акції",
    "description": "Опис — що саме пропонуємо.",
    "old_price": 2000,      # или None, если акция без цен
    "new_price": 1600,      # или None
    "valid_until": "2026-12-31",
},
```

### Как изменить тексты

Все украинские строки лежат в **`utils/texts.py`**. Меняйте текст внутри
кавычек. Не трогайте:
- `{что-то_в_фигурных_скобках}` — сюда бот подставляет данные;
- `<b>`, `<i>`, `<code>` — это жирный, курсив и моноширинный шрифт.

### Как изменить график работы

В `config.py` блок `WORK_HOURS`. Ключ — день недели: `0` понедельник,
`6` воскресенье. `None` = выходной.

### Логотип и картинка прайса

Положите в папку `assets/`:
- **`logo.png`** — показывается в приветствии;
- **`price.jpg`** — уходит картинкой при выборе «Повний прайс».

Файлов нет — бот работает без них, ошибок не будет.

## 6. Бесплатный хостинг 24/7

Боту нужен постоянно включённый компьютер с интернетом. Входящие порты не нужны:
long polling сам ходит наружу, поэтому подойдёт домашний Wi-Fi без белого IP.

### Вариант A. Компьютер владелицы или ваш (0 грн, 5 минут)

Самый быстрый способ для показа и первых недель.

- **Windows:** нажмите `Win+R`, введите `shell:startup`, откроется папка
  автозагрузки. Положите туда **ярлык** на `start_bot.bat` (правый клик по
  файлу → «Отправить» → «Рабочий стол», затем перетащить ярлык в эту папку).
  Теперь бот стартует сам при входе в систему.
- **Linux/macOS:** `./start_bot.sh` в фоне или `systemd`-юнит (см. ниже).

Оба скрипта запуска **сами перезапускают бота**, если он упал из-за обрыва
связи, — отдельный «сторож» не нужен.

**Подводные камни:**
- выключили или усыпили компьютер — бот недоступен, заявки не принимаются;
- отключите спящий режим в настройках питания;
- обновление Windows с ночной перезагрузкой убьёт процесс, если нет автозапуска;
- годится для старта, для боевой работы лучше B или C.

### Вариант B. Oracle Cloud — Always Free (0 грн бессрочно, ~40 минут)

Единственный крупный провайдер с по-настоящему бессрочным бесплатным сервером.
ARM-машина (до 4 ядер / 24 ГБ RAM суммарно) — для бота избыточно с запасом.

Порядок: регистрация → Compute → Create Instance → Ubuntu →
шейп `VM.Standard.A1.Flex` (пометка **Always Free eligible**) → залить проект
через `scp` → оформить `systemd`-сервис.

**Подводные камни:**
- **нужна банковская карта для верификации**, списывается и возвращается ~1 USD;
- **«Out of capacity»** при создании ARM-инстанса в популярных регионах —
  обычное дело, лечится другим доменом доступности или повторными попытками;
- требуются базовые навыки SSH и Linux;
- заброшенный аккаунт Oracle может «переработать» — заходить хотя бы изредка.

### Вариант C. Старый Android-телефон + Termux (0 грн, ~30 минут)

Телефон в розетке — готовый сервер 24/7 с автономным питанием и мобильным
интернетом.

```bash
pkg update && pkg install python
pip install -r requirements.txt
termux-wake-lock
python bot.py
```

**Подводные камни:**
- Termux ставить **только из F-Droid** — версия в Google Play заброшена;
- без `termux-wake-lock` Android убьёт процесс через несколько минут;
- отключите оптимизацию батареи для Termux, иначе система прибьёт его ночью;
- мобильный интернет с NAT не мешает: long polling работает через него.

### Чего избегать

Render, Railway, Fly.io, Replit, PythonAnywhere и Heroku в бесплатных тарифах
**не подходят**: они усыпляют процесс без входящих HTTP-запросов (а у long
polling их нет) либо свернули бесплатные планы. Формально бесплатно —
фактически бот будет засыпать и терять заявки.

## 7. Сценарий демонстрации (4 минуты)

Подготовка: бот запущен, открыты **два окна Telegram** — ваш аккаунт (роль
клиентки) и аккаунт владелицы. Второй экран усиливает эффект: Анна видит,
как заявка прилетает ей в реальном времени.

## 10. Частые вопросы

**`ModuleNotFoundError: No module named 'aiogram'`**
Не активировано виртуальное окружение или не выполнен `pip install -r requirements.txt`.

**В логе `Telegram отклонил токен`**
Токен скопирован не полностью или с лишними пробелами. Возьмите заново:
@BotFather → `/mybots` → бот → *API Token*.

**Владелице не приходят заявки**
Проверьте `ADMIN_IDS` в `.env` (число, без `@` и кавычек) и убедитесь, что
аккаунт владелицы хотя бы раз нажал `/start` в этом боте.

**Обновил код — нужно ли удалять базу?**
Нет. Новые колонки добавляются автоматически при старте, заявки сохраняются.

**Клиентке не пришло напоминание**
Напоминания считаются от времени, которое владелица ввела при подтверждении.
Если заявка не подтверждена в боте — визита в базе нет, и напоминать не о чем.

**Как удалить все данные и начать с чистого листа**
Остановить бота, удалить файл `bot.db`, запустить снова.

**Клиентка написала боту текстом, а он не понял**
Бот работает кнопками, свободный текст он не разбирает — только на шагах
заявки, где спрашивает имя, телефон и комментарий. Это нормально: скажите
клиентке пользоваться кнопками.
