# Drahan Alina beauty space — лендінг

Односторінковий сайт салону краси. Чистий HTML5 + CSS3 (Flexbox/Grid) + Vanilla JS,
без зовнішніх бібліотек (підключено лише Google Fonts).

## Файли

| Файл | Призначення |
| --- | --- |
| `index.html` | Розмітка всіх секцій |
| `styles.css` | Стилі, CSS-змінні та медіазапити |
| `script.js` | Інтерактивність (меню, скрол, модалка, анімації) |

## Як відкрити

- Локально: відкрити `index.html` у браузері (усі шляхи відносні, сервер не потрібен).
- У складі Next.js-проєкту після `npm run dev` — це головна сторінка:
  `http://localhost:3000/`.

За віддачу кореня відповідає route handler `src/app/route.ts`: він читає
цей `index.html` під час збірки й повертає його як звичайну HTML-відповідь,
повз root layout — тому глобальні стилі магазину не втручаються в лендінг.

Спершу тут був `rewrite` у `next.config.ts`, але на хостингу він не
застосовувався і `/` віддавав 404. Route handler — частина застосунку,
а не правило маршрутизації платформи, тож працює скрізь, де запускається Next.

Шляхи до `styles.css` і `script.js` у файлі залишені відносними (щоб
`index.html` відкривався напряму з диска) — route handler робить їх
абсолютними на льоту.

Інтернет-магазин запчастин «Спринтер», який раніше займав `/`,
переїхав на `/sprinter` (весь його код лишився на місці).

## Секції

Хедер → Герой → Про салон → Послуги → Instagram → Контакти → Футер.

## Інтерактивність

- Анімоване бургер-меню (< 1200px) із затемненням та блокуванням скролу.
- Плавний скрол до секцій з урахуванням висоти фіксованого хедера.
- Підсвітка активного пункту меню при скролі (scrollspy).
- Кнопка «Вгору» — з'являється після 60% висоти екрана.
- Поява блоків при скролі через `IntersectionObserver` (з fallback).
- Модальне вікно онлайн-запису з валідацією імені та телефону; після відправки
  показує підтвердження «Дякуємо! Ми зателефонуємо вам за 5 хвилин.»

## Кольори

Задані як CSS custom properties у `:root` (`styles.css`):

| Змінна | Значення |
| --- | --- |
| `--color-white` | `#FFFFFF` |
| `--color-pink-soft` | `#F9E0E8` |
| `--color-pink` | `#FFB6C1` |
| `--color-pink-deep` | `#E8899C` |
| `--color-gray-bg` | `#F8F9FA` |
| `--color-gray` | `#6C757D` |

## Адаптивність

Мобільна база (від 320px), брейкпоінти `768px` та `1200px`.
Враховано `prefers-reduced-motion`.

## Що варто замінити перед публікацією

- Заглушки в секції Instagram — на реальні фото робіт.
- Телефон у посиланні Telegram (`t.me/+380986422627`) — на реальний username,
  якщо номер не прив'язаний до публічного профілю.
- Форма запису наразі не надсилає дані на сервер — підключити бекенд або
  сервіс запису (наприклад, надсилання в Telegram-бот).
