# Фото для сайту-візитки Lesssia Gutsul

Поклади сюди **два файли** з такими іменами:

| Файл | Де показується | Рекомендований формат |
|------|----------------|------------------------|
| `lesssia-photo-1.jpg` | Портрет у Hero (вгорі сайту) | вертикальне, ~800×1000px |
| `lesssia-photo-2.jpg` | Фото в блоці «Про мене» | горизонтальне, ~1000×750px |

## Як додати

1. Перейменуй свої фото на `lesssia-photo-1.jpg` та `lesssia-photo-2.jpg`.
2. Поклади їх у цю папку (`public/images/`).
3. Готово — заглушки на сайті зникнуть автоматично, з'являться твої фото.

> Можна використовувати `.jpg`, `.png` або `.webp` — тоді просто зміни
> розширення у файлі `public/lesssia-gutsul.html` в атрибутах
> `src="images/lesssia-photo-1.jpg"` та `src="images/lesssia-photo-2.jpg"`.
