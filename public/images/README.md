# 📸 Фото сайту

## Hero (перший екран)

Покладіть сюди файл із назвою **`hero.jpg`** — сайт підхопить його
**автоматично**, жодних змін у коді не потрібно. Доки файлу немає,
показується тимчасове стокове фото.

## Галерея «Наш простір» (`gallery/`)

Розділ під «Про нас» гортається горизонтально, як карусель відгуків.
Покладіть файли з назвами **`gallery-1.jpg`** … **`gallery-6.jpg`** у
папку `public/images/gallery/` — вони підхоплюються автоматично, у
тому ж порядку. Хочете більше або менше фото — скажіть, і я
додам/приберу слоти в коді (`src/lib/site.ts`, масив `GALLERY`).

Рекомендації для всіх фото:

- формат **.jpg** (саме таке розширення, у нижньому регістрі);
- від 1200 px по ширині;
- вага бажано до ~500 КБ (можна стиснути на tinypng.com).
