# 📸 Папка для ваших фотографій

Покладіть сюди фото з такими назвами — сайт підхопить їх **автоматично**,
жодних змін у коді не потрібно. Доки файлу немає, показується стокове фото.

| Файл | Де на сайті |
| --- | --- |
| `hero.jpg` | Головне велике фото на першому екрані (Hero) |
| `about.jpg` | Фото у блоці «Про нас» |
| `services/injection.jpg` | Картка «Ін’єкційна косметологія» |
| `services/hardware.jpg` | Картка «Апаратна косметологія» |
| `services/laser.jpg` | Картка «Лазерна епіляція» |
| `services/face.jpg` | Картка «Догляд за обличчям» |
| `services/massage.jpg` | Картка «Масаж та обгортання» |
| `services/antiage.jpg` | Картка «Anti-age програми» |

Рекомендації:

- формат **.jpg** (саме таке розширення, у нижньому регістрі);
- hero та about — вертикальні або квадратні, від 1200 px по ширині;
- фото послуг — від 900 px по ширині;
- вага бажано до ~500 КБ (можна стиснути на tinypng.com).

Якщо хочете інші назви файлів — вони прописані у `src/lib/site.ts` (поле `src`).
