# Telegram-бот онлайн-записи для бьюти-мастера

Бот записи для студии **PROFITIME** (маникюр / педикюр / подология, Украина).
Весь интерфейс для клиенток — на украинском языке. Комментарии в коде и эта
документация — на русском.

**Стоимость разработки и эксплуатации — 0 грн.** Никаких платных API, БД,
хостингов и библиотек. Работает на long polling: не нужны домен, SSL, ngrok
и белый IP.

---

## 1. Запуск за 10 минут

### Шаг 1. Получить токен бота (2 минуты)

1. Откройте Telegram и найдите **@BotFather**.
2. Отправьте `/newbot`.
3. Введите **отображаемое имя** бота, например: `PROFITIME | Запис онлайн`.
4. Введите **username** — латиницей, обязательно заканчивается на `bot`,
   например: `profitime_booking_bot`.
5. BotFather пришлёт строку вида `1234567890:AAH4x-abcdefghijklmnop...` — это
   **токен**. Скопируйте его целиком.

Полезно сразу там же:
- `/setdescription` — описание, которое видно до нажатия «Запустить»;
- `/setuserpic` — аватар студии;
- `/setabouttext` — короткий текст в профиле бота.

### Шаг 2. Узнать свой ADMIN_ID (1 минута)

1. Найдите в Telegram **@userinfobot** и отправьте ему `/start`.
2. В ответе будет строка `Id: 123456789` — это ваш числовой ID.
3. Этот ID нужен от аккаунта **мастера (Анны)** — именно он получит панель
   мастера и все уведомления о записях.

> Пока `ADMIN_ID` не указан, бот работает, но уведомления мастеру уходить не будут.

### Шаг 3. Установка (5 минут)

Нужен **Python 3.11 или новее** (`python --version`).

```bash
git clone <адрес-репозитория>
cd beauty_bot

# Виртуальное окружение (рекомендуется, но не обязательно)
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

### Шаг 4. Настройка (1 минута)

```bash
cp .env.example .env             # Windows: copy .env.example .env
```

Откройте `.env` любым текстовым редактором и заполните две строки:

```env
BOT_TOKEN=1234567890:AAH4x-abcdefghijklmnopqrstuvwxyz012
ADMIN_ID=123456789
```

Файл `.env` в git не попадает (он в `.gitignore`) — секреты не утекут.

### Шаг 5. Запуск (10 секунд)

```bash
python bot.py
```

В консоли должно появиться:

```
2026-08-11 09:00:00 | INFO     | database.db | База даних готова: .../bot.db
2026-08-11 09:00:00 | INFO     | utils.scheduler | Планувальник запущено...
2026-08-11 09:00:01 | INFO     | bot | Бот @profitime_booking_bot запущено. Салон: PROFITIME
```

Всё. Откройте бота в Telegram и нажмите **Запустить / Start**.

Если в `.env` чего-то не хватает, бот не упадёт с трейсбеком, а напишет
понятным текстом, что именно исправить.

Остановка — `Ctrl+C`.

## 2. Что настраивается и где

**Весь прайс, услуги, часы работы и контакты — в одном файле `config.py`.**
В хендлерах нет ни одной захардкоженной цены или строки расписания.

| Что | Переменная в `config.py` |
|---|---|
| Название студии, телефон, Instagram, адрес | `SALON_NAME`, `PHONE`, `INSTAGRAM_URL`, `ADDRESS` |
| Услуги, цены, длительность | `SERVICES` |
| Правила салона | `SALON_RULES` |
| Рабочие дни и часы | `WORK_SCHEDULE` |
| Шаг сетки времени (по умолчанию 30 мин) | `SLOT_STEP_MIN` |
| На сколько дней вперёд открыта запись | `BOOKING_HORIZON_DAYS` |
| Лимит активных записей на клиента | `MAX_ACTIVE_BOOKINGS` |
| Минимальный запас времени до визита | `MIN_LEAD_TIME_MIN` |
| За сколько часов напоминать | `REMINDER_OFFSETS_H` |
| Через сколько дней звать на повторный визит | `FOLLOWUP_DAYS` (по категориям) |
| В котором часу отправлять такие приглашения | `FOLLOWUP_HOUR` |
| Полностью выключить приглашения | `FOLLOWUP_ENABLED = False` |
| Часовой пояс | `TIMEZONE` |

> ⚠️ **Цены, перечень услуг и правила салона в `config.py` — предварительные:
> прайс составлен по типовому прайсу студий маникюра/педикюра/подологии,
> правила — по типовым правилам записи.
> Обязательно подтвердить у Анны перед показом.** Правки занимают 2 минуты:
> открыть `config.py`, поменять текст, перезапустить бота.
> Отдельно нужны от Анны: **адрес студии** (`ADDRESS`, сейчас пустой) и
> интервалы повторного визита (`FOLLOWUP_DAYS`) — она лучше знает, через сколько
> недель клиентки обычно возвращаются.

Длительность услуги стоит держать кратной `SLOT_STEP_MIN` (30 / 60 / 90 / 120) —
тогда сетка времени выглядит аккуратно.

## 3. Что умеет бот

### Клиентка

- **📅 Записатися** — 5 шагов: направление → услуга → дата → время → имя и телефон
  → карточка подтверждения. На каждом шаге есть «⬅️ Назад» и «❌ Скасувати».
- **📋 Мої записи** — список своих записей и отмена в два тапа (с переспросом).
- **💅 Послуги та ціни** — прайс из `config.py`.
- **📍 Контакти** — телефон, адрес, график, кнопка Instagram, «📜 Правила салону»
  и «✍️ Написати майстру» (сообщение уходит мастеру прямо в Telegram).
- **Напоминания** — автоматически за 24 часа и за 2 часа до визита.
- **Возврат клиентов** — через 3–6 недель после визита (интервал свой для маникюра,
  педикюра и подологии) бот сам предлагает записаться снова, с кнопкой
  «📅 Записатися знову». Не пишет тем, кто уже записан вперёд, и не напоминает
  дважды об одном визите.

### Мастер (только для `ADMIN_ID`)

- Мгновенное уведомление о **новой записи** и о **отмене клиентом**
  — с именем, телефоном и ссылкой на профиль клиентки.
- `/today` — записи на сегодня с итоговой суммой.
- `/week` — записи на 7 дней вперёд.
- Отмена любой записи одной кнопкой — клиентке автоматически уходит уведомление.
- `/block` — пометить день или интервал как недоступный (учёба, личные дела).
  Заблокированное время исчезает из выдачи клиенткам.
- `/blocks` — список блокировок и снятие в один тап.

### Защита от бардака

| Риск | Как закрыт |
|---|---|
| Запись на прошедшее время | Слоты фильтруются по текущему времени + `MIN_LEAD_TIME_MIN` |
| Двойное бронирование | Три уровня: фильтр слотов → перепроверка в транзакции `BEGIN IMMEDIATE` → частичный `UNIQUE`-индекс в SQLite |
| Наложение услуг разной длительности | Проверка пересечения интервалов `[начало, начало + длительность)` |
| Спам записями | Не больше `MAX_ACTIVE_BOOKINGS` (по умолчанию 2) активных записей на пользователя |
| Отмена чужой записи | Отмена клиентом идёт с фильтром по `user_id` в SQL |
| «Залипшее» состояние FSM | Команды и кнопки меню перехватываются в любом состоянии, `/cancel` работает всегда |
| Нажатие кнопки из старого сообщения после перезапуска | Fallback-роутер отвечает понятным текстом и возвращает в меню |
| Клиентка заняла слот, пока другая думала | Перепроверка перед вставкой + понятное «час щойно зайняли, оберіть інший» |

    ├── texts.py           ВСЕ украинские строки и форматтеры

## 5. Бесплатный хостинг 24/7

Боту нужен постоянно включённый компьютер с интернетом. Входящие порты не нужны —
long polling сам ходит наружу, поэтому подойдёт даже домашний Wi-Fi без белого IP.

### Вариант A. Компьютер мастера или ваш ПК (0 грн, 5 минут)

Самый быстрый способ для показа и первых недель работы.

- **Linux/macOS:** `nohup python bot.py > bot.log 2>&1 &`, для автозапуска — `systemd`-юнит или `launchd`.
- **Windows:** ярлык `python bot.py` в папке автозагрузки
  (`Win+R` → `shell:startup`) или задача в «Планировщике заданий»
  с триггером «При входе в систему».

**Подводные камни:**
- Выключили/усыпили компьютер — бот недоступен, клиентки не могут записаться.
  Отключите спящий режим в настройках питания.
- Пропал интернет — записи не принимаются (aiogram сам переподключится, когда сеть вернётся).
- Обновление Windows с перезагрузкой ночью убьёт процесс, если нет автозапуска.
- Подходит для демо и старта; для боевой работы лучше вариант B или C.

### Вариант B. Oracle Cloud — Always Free (0 грн бессрочно, ~40 минут)

Единственный крупный провайдер с по-настоящему бессрочным бесплатным сервером.
Дают ARM-машину (до 4 ядер / 24 ГБ RAM в сумме) — для бота это избыточно с запасом.

Порядок: регистрация → Compute → Create Instance → образ Ubuntu →
шейп `VM.Standard.A1.Flex` (пометка **Always Free eligible**) → залить проект
через `scp`/`git clone` → оформить `systemd`-сервис.

**Подводные камни:**
- **Нужна банковская карта для верификации.** Списывается и возвращается ~1 USD.
  Аккаунт не переходит на платный тариф автоматически, но карту привязать придётся.
- **«Out of capacity»** при создании ARM-инстанса в популярных регионах — обычная
  ситуация. Лечится выбором другого домена доступности или повторными попытками.
- Требуются базовые навыки SSH и Linux. Без них настройка займёт не 40 минут, а вечер.
- Простаивающие Always Free инстансы Oracle может «переработать» —
  на практике работающего бота это не касается, но забрасывать аккаунт нельзя.

### Вариант C. Старый Android-телефон + Termux (0 грн, ~30 минут)

Недооценённый вариант: телефон в розетке — это готовый сервер 24/7 с автономным
питанием и мобильным интернетом.

```bash
pkg update && pkg install python git
pip install -r requirements.txt
termux-wake-lock          # запретить системе усыплять процесс
python bot.py
```

**Подводные камни:**
- Termux нужно ставить из **F-Droid** — версия в Google Play заброшена и сломана.
- Без `termux-wake-lock` Android убьёт процесс через несколько минут.
- Нужно отключить оптимизацию батареи для Termux, иначе система прибьёт его ночью.
- Мобильный интернет с NAT — не проблема, long polling работает через него нормально.

### Чего избегать

Render, Railway, Fly.io, Replit, PythonAnywhere и Heroku в бесплатных тарифах
**не подходят**: они либо усыпляют процесс без входящих HTTP-запросов (а у long
polling их нет), либо свернули бесплатные планы. Формально «бесплатно» — фактически
бот будет засыпать и терять записи.

## 6. Сценарий демонстрации клиентке (3 минуты)

Подготовка: заранее запустите бота, откройте **два окна Telegram** — свой аккаунт
(роль клиентки) и аккаунт Анны (роль мастера). Второй экран/телефон очень
усиливает эффект: Анна видит, как уведомление прилетает ей в реальном времени.

### Часть 1. Глазами клиентки (90 секунд)

| # | Что нажать | Что говорить |
|---|---|---|
| 1 | `/start` | «Клиентка открывает бота — сразу видит название студии и меню» |
| 2 | **💅 Послуги та ціни** | «Весь прайс под рукой, звонить и спрашивать не нужно» |
| 3 | **📅 Записатися** | «Запись — четыре тапа» |
| 4 | **💅 Манікюр** | |
| 5 | **Манікюр + покриття гель-лаком** | «Цена и длительность сразу видны» |
| 6 | Любая дата | «Показываются только рабочие дни — воскресенье бот не предложит» |
| 7 | Любое время | «И только реально свободное время. Занятые слоты клиентка не видит вообще» |
| 8 | Имя → номер (**📱 Надіслати мій номер**) | «Номер подставляется одной кнопкой» |
| 9 | **✅ Підтвердити** | «Готово. Запись есть, и бот сам напомнит за сутки и за 2 часа» |

### Часть 2. Глазами мастера (60 секунд)

| # | Что показать | Что говорить |
|---|---|---|
| 10 | Уведомление у Анны | «Вот оно — прилетело мгновенно, с услугой, временем, именем и телефоном» |
| 11 | `/today` | «Весь день перед глазами, с суммой за день» |
| 12 | `/week` | «И вся неделя» |
| 13 | `/block` → день → «🚫 Весь день» | «Уехали на обучение — помечаете день, и он исчезает из записи» |

### Часть 3. Добивающие 30 секунд

| # | Что показать | Что говорить |
|---|---|---|
| 14 | Снова **📅 Записатися** на тот же слот | «Дважды на одно время записаться невозможно — время уже исчезло из списка» |
| 15 | **📋 Мої записи** → отмена | «Клиентка отменила сама — вам сразу пришло уведомление, время снова свободно» |
| 16 | **📍 Контакти** → **📜 Правила салону** | «Правила записи и отмены — один раз написали, больше не объясняете каждой» |

**Ключевая фраза в конце:** «Ночью, пока вы спите, клиентка записалась сама.
Утром вы просто открываете `/today`».

## 7. Чек-лист перед показом

**За день до показа**

- [ ] Цены и список услуг в `config.py` **подтверждены у Анны** и исправлены.
- [ ] Правила салона (`SALON_RULES`) прочитаны Анной и переписаны под её порядки.
- [ ] Заполнен `ADDRESS` — иначе блок с адресом в контактах не покажется.
- [ ] Интервалы `FOLLOWUP_DAYS` согласованы с Анной (21/35/42 дня — предположение).
- [ ] Рабочие часы в `WORK_SCHEDULE` совпадают с реальным графиком студии.
- [ ] Название студии, телефон и ссылка на Instagram проверены (`config.py`).
- [ ] Заполнено поле `ADDRESS` в `config.py`, если адрес нужно показывать.
- [ ] У бота установлены аватар и описание через @BotFather.

**За час до показа**

- [ ] `python bot.py` стартует без ошибок, в логе есть строка `Бот @... запущено`.
- [ ] `ADMIN_ID` = ID **аккаунта Анны**, а не ваш (иначе уведомления пойдут не туда).
- [ ] С аккаунта Анны отправлен `/start` — иначе Telegram не даст боту ей писать
      и меню команд мастера не появится.
- [ ] Удалите тестовые записи: остановите бота, удалите файл `bot.db`, запустите снова.
- [ ] Проверьте, что в базе нет блокировок, закрывающих ближайшие дни (`/blocks`).

**Прямо перед показом**

- [ ] Интернет на устройстве, где крутится бот, стабилен; спящий режим отключён.
- [ ] Оба окна Telegram открыты: клиентка и мастер.
- [ ] Полный прогон сценария из раздела 6 сделан хотя бы один раз.
- [ ] Телефон заряжен, уведомления Telegram не отключены и не в беззвучном режиме.
- [ ] Слово «демо/тест» в разговоре не звучит — бот показывается как готовый продукт.

**Быстрая проверка работоспособности (2 минуты)**

- [ ] `/start` → появилось меню из 4 кнопок.
- [ ] Полный цикл записи проходит до «✅ Вас записано!».
- [ ] Мастеру пришло уведомление «🔔 НОВИЙ ЗАПИС».
- [ ] `/today` у мастера показывает эту запись.
- [ ] «📋 Мої записи» → отмена работает, мастеру пришло уведомление об отмене.
- [ ] После отмены освободившееся время снова появляется в списке.
- [ ] `/cancel` в середине записи возвращает в главное меню без ошибок.

## 8. Доступно в полной версии

Текущая версия закрывает полный цикл записи. Следующим этапом подключается:

- **Онлайн-предоплата** — бронь подтверждается только после внесения аванса.
  Убирает неявки, которые сейчас съедают до 20 % рабочего времени.
- **Синхронизация с Google Calendar** — записи в привычном календаре мастера,
  доступ с любого устройства.
- **База клиентов с историей визитов** — что делали в прошлый раз, какой цвет,
  какая база, аллергии и особенности.
- **Рассылки и акции** — сообщение всем клиенткам в пару кликов: окно в графике,
  сезонное предложение, новая услуга.
- **Программа лояльности** — накопительные визиты, персональные скидки, бонусы
  за приведённую подругу.
- **Аналитика и отчёты** — выручка по неделям и месяцам, самые доходные услуги,
  процент отмен, загрузка по дням недели.
- **Несколько мастеров** — запись к конкретному специалисту, отдельные графики
  и раздельная статистика.
- **Веб-панель администратора** — управление записями и прайсом из браузера,
  без команд в Telegram.
- **Автоматическое резервное копирование** — база сохраняется по расписанию,
  данные не теряются при поломке устройства.
- **Отзывы после визита** — бот сам просит оценку и собирает обратную связь.

## 9. Возможные вопросы

**Бот падает при запуске: `ModuleNotFoundError: No module named 'aiogram'`**
Не активировано виртуальное окружение или не выполнен `pip install -r requirements.txt`.

**В логе `Telegram відхилив токен`**
Токен в `.env` скопирован не полностью или с лишними пробелами/кавычками.
Возьмите его заново в @BotFather командой `/mybots` → бот → *API Token*.

**Мастеру не приходят уведомления**
Проверьте `ADMIN_ID` в `.env` (это число, без `@` и кавычек) и убедитесь, что
аккаунт мастера хотя бы раз нажал `/start` в этом боте.

**Клиентка не видит нужную дату**
Либо это выходной по `WORK_SCHEDULE`, либо на этот день не осталось окна нужной
длины, либо день закрыт через `/block` (проверьте `/blocks`).

**Как удалить все записи и начать с чистого листа**
Остановить бота, удалить файл `bot.db`, запустить снова.

**Обновил код — нужно ли удалять базу?**
Нет. Новые колонки добавляются автоматически при старте, записи сохраняются.

**Клиентке не пришло приглашение записаться снова**
Оно уходит раз в сутки в `FOLLOWUP_HOUR` и только если: визит уже закрыт ночной
уборкой, прошло не меньше `FOLLOWUP_DAYS` для этой категории, визит не старше
`FOLLOWUP_MAX_AGE_DAYS` и клиентка ещё не записана вперёд.

**Время показывается неправильно**
Проверьте `TIMEZONE` в `config.py` и часовой пояс на машине, где запущен бот.
