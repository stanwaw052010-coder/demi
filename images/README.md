# 📸 Папка для фото

Скріншоти робіт у портфоліо (`rayskaya.jpg`, `profitime.jpg`,
`dentalnataly.jpg`, `crossclub.jpg`) **вже додані** й показуються на сайті.

Залишилось додати лише **особисті фото для hero** (теніс). Поклади сюди
файли з такими назвами — вони з'являться автоматично, код чіпати не треба:

| Що це | Назва файлу |
|---|---|
| Твоє головне фото (теніс) | `tennis-main.jpg` |
| Фонове фото (теніс) | `tennis-bg.jpg` |

## Як завантажити на GitHub
1. Відкрий цю папку `images` на GitHub.
2. **Add file → Upload files** → перетягни фото (перейменовані як у таблиці).
3. **Commit changes**. Готово.

Формат може бути `.jpg`, `.png` або `.webp` — сайт сам знайде файл за назвою.
Поки файлу немає — показується акуратний плейсхолдер із камерою.
