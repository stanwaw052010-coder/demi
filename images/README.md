# 📸 Папка для фото

Просто поклади сюди свої фото з **точно такими назвами** — і вони
автоматично з'являться на сайті. Редагувати код **не треба**.

| Що це | Назва файлу (клади сюди) | Де показується |
|---|---|---|
| Твоє головне фото (теніс) | `tennis-main.jpg` | Hero, передній план |
| Фонове фото (теніс) | `tennis-bg.jpg` | Hero, задній план |
| Скріншот сайту Rayskaya Beauty | `rayskaya.jpg` | Картка в «Портфоліо» |
| Скріншот сайту Спабель | `spabel.jpg` | Картка в «Портфоліо» |

## Як завантажити на GitHub (без коду)
1. Відкрий цю папку `portfolio/images` на GitHub.
2. Натисни **Add file → Upload files**.
3. Перетягни свої фото, **перейменувавши** їх точно як у таблиці вище.
4. Натисни **Commit changes**. Готово — фото з'явиться на сайті.

## Важливо
- Назва має збігатися **точно** (напр. `rayskaya.jpg`, маленькими літерами).
- Формат можна будь-який популярний — `.jpg`, `.png` або `.webp`
  (сайт сам знайде потрібний; головне — правильна назва без пробілів).
- Поки файлу немає — на сайті показується акуратний плейсхолдер із
  іконкою камери. Нічого не «ламається».
- Рекомендовані пропорції: фото в hero — вертикальні/квадратні,
  скріншоти робіт — горизонтальні (приблизно 16:10).
